Tela de entrar · o lado esquerdo

Hoje o lado esquerdo da tela de entrar é o desenho de exemplo do Design System (círculos e o ícone de imagem). A ideia é usar esse espaço para mostrar pedacinhos do próprio Facter Chef: quem chega já vê o que o sistema faz. O lado direito (logo centralizado, Entrar e "Fale com o suporte") fica como está. As três opções usam peças que já existem nas telas, com números de exemplo.

Recomendação: A

A vitrine é a que mais "vende" o sistema numa olhada, e cada cartão vem de uma tela que já existe (fica fácil manter). O fundo chocolate usa o mesmo token da faixa do Início, que já funciona no modo escuro.

Como fazer: o AuthLayout.Image do DS só aceita foto ou o desenho de exemplo (não recebe conteúdo dentro). Por isso o lado esquerdo vira um painel nosso com as mesmas medidas dele (hidden xl:block w-1/2), com os cartões montados com as peças do DS. Os números são de exemplo e ficam fixos (a pessoa ainda não entrou, então não há dados dela).
