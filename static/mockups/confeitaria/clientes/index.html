Clientes: 3 caminhos com a tabela do DS

Hoje Clientes é uma pilha de cartões, um por pessoa, com muito espaço e pouca informação: dá para ver o telefone, mas não quem compra, quando comprou pela última vez ou quem faz aniversário. Os três caminhos usam o DataTable do Design System (o mesmo das listas do Truck), no Conteiner padrão. O que precisa de dado novo da API está marcado com API.
