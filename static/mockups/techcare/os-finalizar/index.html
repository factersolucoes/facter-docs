C

"Pronto" sem diálogo

"Cliente aprovou" continua levando direto para Conserto. O "Registrar conserto" vira um botão sem diálogo, "Pronto", e o que foi feito passa a ser escrito na ficha, como o "Encontrei". A entrega mantém a conferência, porque é quando o aparelho sai. Atenção: hoje a API só conclui a OS com a solução escrita; para o "Pronto" sem diálogo, ela teria de aceitar concluir sem solução.
