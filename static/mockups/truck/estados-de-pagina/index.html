Estados de página · telas de sistema

A família de páginas inteiras de feedback. Um esqueleto só: ilustração (mesmo tamanho e posição) → código → título → texto → ação. Muda a ilustração, a copy, a ação e o contexto — logado (área de conteúdo, sidebar fica) ou deslogado (tela cheia com a logo). Mesma altura, mesma linguagem visual (azul + verde). Vazio, busca sem resultado e custo oculto não entram — são do EmptyState por tela.

Como se comporta

O que vale pra família inteira.

Componente: um PageState (o Hero) que recebe ilustração, código, título, texto e ações; cada estado é uma config dele.
Contexto: logado na área de conteúdo (sidebar fica); deslogado é tela cheia com a logo.
Rota: catch-all * no shell → 404; o error boundary fica só pro 500 e serializa o erro.
Copy (pt-BR, i18n): título curto; ação é verbo; mostra o endereço/id tentado, nunca código cru.
Linguagem visual: azul (marca) + verde (acento), mesmo chão, traço e escala; os slots de ilustração aceitam Storyset na mesma medida.
Implementa já: 404 (logado + deslogado), recurso, 403 e 500. Sessão, offline, manutenção e plano entram com o PWA e o ecossistema.
