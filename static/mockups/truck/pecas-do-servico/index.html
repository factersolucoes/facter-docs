⚙O que se configura uma vez

Só o kit do tipo de serviço, que já existe hoje. Muda uma coisa: cada peça diz se a quantidade é fixa ou vai por lado, por eixo ou por roda. Sem kit, o serviço nasce sem peças e o mecânico escolhe na etapa 3.

Configurações · Tipos de serviço
Troca de lona de freio
Depois, se precisar: peça que muda conforme o veículo. Quando a mesma lona tem códigos diferentes por marca de eixo (Randon usa LF-4707, Librelato usa LF-4720), o kit passa a dizer só "lona de freio" e uma lista de aplicação escolhe o código pelo veículo. Com a Suzano, essa lista viria do SAP. Fica para uma segunda fase: no começo, cada kit aponta para uma peça só, e o mecânico troca o código na etapa 3 quando for outra.
